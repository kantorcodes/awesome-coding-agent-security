# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion on the facts. Harassment, personal attacks and the publication of other people's private information are not accepted.

Security discussions have one extra rule: never post working exploit payloads, stolen tokens, or links to live malicious repositories in issues or pull requests.

Report unacceptable behavior privately through this repository's [private reporting form](https://github.com/nukoe-labs/awesome-coding-agent-security/security/advisories/new), or to GitHub through its [abuse report form](https://github.com/contact/report-abuse). Reports are handled confidentially.
